# LAB-TASK-2-OOP-AHMED
This C++ program shows basic Object-Oriented Programming (OOP) concepts by creating a class called BankAccount. The class stores information about a bank account such as the account holder’s name, account number, and balance. These variables are kept private to follow the concept of encapsulation, so they cannot be accessed directly from outside the class. The program uses setter functions to set values with proper validation, such as checking that the name is not empty, the account number is a valid 5-digit number, and the balance is not negative. Getter functions are provided to safely access the stored data. The class also includes a default constructor, a parameterized constructor, and a copy constructor to show different ways of creating objects. Finally, the displayAccountInfo() function prints the account details in a clear format. This program helps beginners understand how classes, objects, constructors, and data validation work in C++.
